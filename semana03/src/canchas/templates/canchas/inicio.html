Guía para registrar una reserva

Sigue estos pasos en orden para crear una reserva completa en el sistema.

  1. Paso 1: Registrar un Cliente

    Crea el cliente que realizará la reserva, si todavía no existe.

    Registrar cliente

  2. Paso 2: Registrar una Sede

    Registra la sede como información del lugar. Este paso es opcional.

    Registrar sede

  3. Paso 3: Registrar una Cancha

    Crea la cancha que estará disponible para recibir horarios.

    Registrar cancha

  4. Paso 4: Registrar un Horario

    Asocia un horario a la cancha y déjalo marcado como disponible.

    Registrar horario

  5. Paso 5: Crear la Reserva

    Selecciona el cliente y el horario disponible que ya registraste.

    Crear reserva
